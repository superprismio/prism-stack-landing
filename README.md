# Prism Refactory Landing

Landing page app for Prism Refactory.

Current intent:

- keep the visual language aligned with Superprism
- shift the message toward Prism Refactory as the product-facing layer
- keep Prism Stack available as the technical/deployable descriptor
- focus on shared intelligence, community workflows, and Discord-first coordination

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Development

```bash
npm install
npm run dev
```

Then open:

```text
http://localhost:3000
```
